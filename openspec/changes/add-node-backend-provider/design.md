## Design Decisions

### 1. Minimal Framework-Free Starter (`node:http`)

Rather than committing to Express, Fastify, or Koa in the language provider, the scaffold uses Node.js standard library `node:http`. This keeps the starter zero-dependency, fast to boot, and free of accidental framework opinions. Users can add any web framework by updating `package.json` and `src/index.js`.

### 2. Built-in Tooling (`node --watch` and `node --test`)

Node 22 LTS provides built-in process reload (`node --watch`) and a built-in test runner (`node --test`). This avoids third-party dev dependencies like `nodemon` or test frameworks like `vitest`/`jest` in the default scaffold.

Starter scripts:
```json
{
  "name": "<name>",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "dev": "node --watch src/index.js",
    "start": "node src/index.js",
    "test": "node --test"
  }
}
```

### 3. Base Image and Multi-Stage Dockerfile

The generated Dockerfile uses `node:22-slim@sha256:c3de60bf2f9dd0ac6370e6117950ff62d6e339527e7472301c9c78a017978392`:
- `base` stage: installs `curl` for container health checks, copies `package*.json`, runs `npm ci` or `npm install --omit=dev`, and copies `src/`.
- `test` stage: runs `npm test` so CI can execute service tests in the image.
- `production` stage: exposes the assigned port, configures the `HEALTHCHECK` probe against `http://localhost:${PORT:-4000}/health`, and runs `CMD ["node", "src/index.js"]`.

### 4. Tilt Live Update Behavior

- When a source file under `src/` changes, Tilt syncs the file directly into `/app/<resource>/src/`. The running `node --watch` process reloads instantly without rebuilding the container.
- When `package.json` or generated engine configurations change, Tilt triggers an image rebuild.
- Bunfig and `.npmrc.docker.autogenerated` syncs are excluded since Node does not consume Bun configuration.

### 5. CLI Registry Integration

- `node` is added to `BACKEND_LANGUAGES` in `cli/src/backend-languages/registry.ts`.
- Selection is case-insensitive (`--language Node` or `--language node`).
- `--framework` cannot be combined with `--language node` (framework flags apply only to the Bun runtime).
- Omitting `--language` continues to produce byte-identical Bun + Hono output.
