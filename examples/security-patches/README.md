# Temporary dependency security patches

These packages are local downstream patches for the example dependency trees. The readable source diffs are in `braces.patch`, `deepmerge.patch` and `node-forge.patch`; the matching packed packages are in each example's `vendor/` directory. Each package starts from the exact npm release previously in its lockfile and applies the cited upstream security change. Replace the local packages with official npm releases when they include these fixes.

- `braces` `3.0.4-flisk.1`: based on npm `braces@3.0.3`; applies source changes from [FSDevelop/braces commit `28d440b5dd449dbf1fe6f3506cf94ecca4d02660`](https://github.com/FSDevelop/braces/commit/28d440b5dd449dbf1fe6f3506cf94ecca4d02660), the closed upstream PR #72 for GHSA-vfj7-8cjw-p6xm. It bounds parsing and recursive AST walks at 100 levels. Used by the MikroORM and Nitro examples.
- `deepmerge` `4.3.2-flisk.1`: based on npm `deepmerge@4.3.1`; applies the `index.js` change from [Adam-Aghili/deepmerge commit `5dd5fa70d2ea0b1e395d7d2003bb94e6ba775cb7`](https://github.com/Adam-Aghili/deepmerge/commit/5dd5fa70d2ea0b1e395d7d2003bb94e6ba775cb7), the open upstream PR #277 for GHSA-gcqx-w48m-w2h4, to `index.js`, `dist/cjs.js` and `dist/umd.js`. It writes an own `__proto__` key as a data property so a merge can no longer set the returned object's prototype. Used by the Nitro example.
- `node-forge` `1.4.1-flisk.1`: based on npm `node-forge@1.4.0`; applies `lib/rsa.js` from [Krysthyan/forge commit `ceba34402e329f0365134f23fe19898756527d65`](https://github.com/Krysthyan/forge/commit/ceba34402e329f0365134f23fe19898756527d65), the proposed fix in upstream PR #1152 for GHSA-86w9-cpqp-85rv. It validates the nested `DigestAlgorithm` element count during RSA PKCS#1 v1.5 verification.

The Flisk-local version suffixes distinguish these patched copies from upstream releases; none of these copies has been published to npm.
