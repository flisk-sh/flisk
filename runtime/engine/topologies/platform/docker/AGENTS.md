# AGENTS.md - Docker Platform Infrastructure

## Purpose

Docker image building, golden image layers, and Dockerfile generation for all services.

## Key Concepts

### Golden Image Architecture (L1-L4)
```
L1: Base (Alpine OS with essential tools, runtime environment variables)
L2: Dependencies (package manifests and installed dependencies, cached)
L3: Builder (backend compile, frontend build, production dependency pruning)
L4: Runtime (backend on Bun, frontend on Nginx or Bun static)
```

## Key Files

### Golden Images
- **`build/golden_image.star`** - GoldenImage struct with L1-L4 builders
- **`build/golden_image_*.star`** - Build, constants, and Dockerfile helpers used by `GoldenImage`
- **`dockerfile/dockerfile.star`** - Dockerfile generation for apps
- **`constants.star`** - Docker constants, image names

### Layer Building
- **`layers/l1_base_layers.star`** - Alpine OS base and runtime environment
- **`layers/l2_dependency_layers.star`** - Dependency installation
- **`layers/l3_builder_layers.star`** - Build stage
- **`layers/l4_runtime_layers.star`** - Minimal runtime

### Specialized
- **`layers/prisma/`** - Prisma-specific Docker layers
- **`generators/golden_docker_generator_v2.star`** - Current generator (v2)

## Common Tasks

### Generate Dockerfile for service
```starlark
load("./dockerfile/dockerfile.star", "generate_app_dockerfile")
dockerfile = generate_app_dockerfile(res_path, resource_name, cmd = start_command)
```

### Get golden image
```starlark
load("./build/golden_image.star", "GoldenImage")
image = GoldenImage.get_layer("l2")
```

## Integration

- Called by `engine/topologies/tilt/resources/orchestrator/generators/manifest_resource.star` - when building service resources
- Used by discovery - to determine Dockerfile paths
- Outputs to services' `autogenerated/Dockerfile.*.autogenerated`

## Important Notes

- Golden images use digests for cache invalidation
- L2 layer caches `node_modules` for faster rebuilds
- Each service's Dockerfile starts `FROM {project}/golden-image-l4:latest`
