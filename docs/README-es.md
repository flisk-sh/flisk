Pasa de una carpeta vacía a un stack en ejecución con un solo comando. Define cada servicio en `service.json` y ejecuta `tdk up`. No hace falta Kubernetes en la máquina.

Inicio rápido:

```bash
npm install -g @tdk-landscape/tdk-cli-core
mkdir shop && cd shop
tdk project --yes
tdk resource orders-api --type backend --stack shop --yes
tdk up shop
```

La guía completa está en el [README en inglés](../README.md).
