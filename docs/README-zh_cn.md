从空文件夹到运行中的技术栈，只需一条命令。在 `service.json` 中定义每个服务，然后运行 `flisk up`。机器上不需要 Kubernetes。

快速开始:

```bash
npm install -g flisk
mkdir shop && cd shop
flisk project --yes
flisk resource orders-api --type backend --stack shop --yes
flisk up shop
```
