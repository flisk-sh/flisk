Flisk brand sheet

Your whole stack, running with one command.

Flisk turns an empty folder into a running local stack. This sheet covers the colors, type and mark used across the README, docs and CLI.

Mark and wordmark

flisk.

Nodes are services. The teal node is the one that is running.

Color

Signal#61f0d3
Ink#0c1417
Slate#1b2a30
Mist#71717a
Paper#f4f7f6

Signal is the only accent. Text on signal is always Ink.

Typography

IBM Plex Sans, semibold for headings.

Body text is IBM Plex Sans regular at 16px with 1.6 line height, kept near 65 characters per line.

JetBrains Mono for commands: flisk up

Terminal

$ flisk up ✓ postgres running ✓ api running ✓ web running stack ready in 14s

Voice

Say: "Run flisk up. Your services start."

Avoid: "Seamlessly orchestrate your revolutionary stack."

Errors: "Docker is not running. Start it, then run flisk doctor."
