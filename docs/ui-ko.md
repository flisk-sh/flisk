# `flisk ui` 단축키

> 이 문서는 [ui.md](ui.md)의 한국어 번역입니다.

`flisk ui`는 실행 중인 스택을 대화형 터미널 대시보드로 엽니다. 대시보드에서 처리하는 단축키 목록은 다음과 같습니다.

| 단축키 | 기능 |
|---|---|
| `1`–`5` | 개요(Overview), 리소스(Resources), 이벤트(Events), 파일(Files), 설정(Config) 탭으로 이동 |
| `Tab` / `Shift+Tab` | 다음 / 이전 탭으로 이동 |
| `↑`/`↓` 또는 `j`/`k` | 선택 항목 이동 |
| `g` / `G`, `Home` / `End` | 첫 번째 / 마지막 항목으로 이동 |
| `PgUp` / `PgDn` | 한 페이지 단위 이동 |
| `Enter` 또는 `Space` | 선택한 스택, 서비스 또는 파일 열기 |
| `Esc` | 한 단계 상위로 이동 (파일 → 서비스 → 스택). 최상위 화면에서는 "Press q to quit"만 표시 |
| `/` | 검색. `Enter`는 필터 유지, `Esc`는 필터 해제 |
| `r` | 새로고침. Events 탭에서는 이벤트를 다시 로드 |
| `e` | 활성화된 서비스만 보기 / 전체 서비스 보기 토글 |
| `t` | 하단 툴팁 표시 토글 |
| `m` | 마우스 지원 토글 |
| `?` | 도움말 패널 표시. 아무 키나 누르면 닫힘 |
| `q` | 종료 |

## 플래그

- `--no-animations`: 애니메이션 비활성화 (정적 스피너 텍스트).
- `--high-contrast`: 고대비 색상 활성화.

## ASCII 모드

실행 환경에서 색상을 사용하지 않도록 설정된 경우 `flisk ui`는 자동으로 일반 ASCII 모드로 전환됩니다:

- `NO_COLOR` 환경 변수가 설정된 경우 (빈 값 포함), 또는
- `TERM` 환경 변수가 `dumb`으로 시작하는 경우 (대소문자 무관).

ASCII 모드에서는 색상과 패널 테두리가 표시되지 않으며, `--high-contrast` 플래그는 적용되지 않습니다. 기존 기호는 다음과 같이 텍스트로 대체됩니다:

| 위치 | 일반 모드 | ASCII 모드 |
|---|---|---|
| 배너 및 선택된 행 표시자 | `▓▒░` (끝: `░▒▓`) | `>>>` (끝: `<<<`) |
| 하단 항목 간 구분 기호 | ` │ ` | ` \| ` |
| 가로 구분선 | `─` | `-` |
| 섹션 제목 | `┌─ Resources ─` | `[ Resources ]` |
| 스택 및 서비스 제목 | `┌─ NAME ─┐` | `--- NAME ---` |
| 상태: 정상(healthy), 진행 중(in progress), 실패(failed), 알 수 없음(unknown) | `✓` `○` `✗` `?` | `[+]` `[~]` `[x]` `[?]` |
| 스택에 속한 서비스 | `├─ ` 및 `└─ ` | `\|- ` 및 `L- ` |
| 폴더 열림, 닫힘 (Files 탭) | `▼` `▶` | `[-]` `[+]` |
| 파일 유형: Docker, Tilt, 설정, Prisma, 생성된 파일, 기타 | 이모지 | `[D]` `[T]` `[C]` `[P]` `[G]` `[?]` |
| 개요 수량: 스택 내부, 스택 외부 | `●` `○` | `[+]` `-` |
| 하단 토글 | `🖱️` `ℹ️` `✓ enabled` (또는 `✓ all`) | `Mouse` `Info` `[+] enabled` (또는 `[+] all`) |
| 툴팁 접두사 | `ℹ ` | `[i] ` |
| 로딩 스피너 | 점자 도트 | `-` `/` `\|` `\` |
| 오류 표시, 빈 상태 표시 | `✗` `◉` | `[x]` `[*]` |
| 단축키 안내 내 화살표 키 | `↑/↓` | `UP/DOWN` |

직접 확인하려면 `NO_COLOR=1 flisk ui`를 실행하세요. 동일한 동작 방식이 [`cli/README.md`](../cli/README.md)에도 설명되어 있습니다.

## Events 탭

Events 탭은 Tilt에서 정보를 읽어오므로 Tilt가 실행 중이어야 합니다. 실행 중이 아닌 경우 "Tilt is not running or its UI is unreachable" 메시지와 함께 `flisk up` 실행 안내가 표시됩니다. 해당 탭에서 `r`을 누르면 다시 시도합니다.
