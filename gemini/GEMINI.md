# Flisk

[Flisk](https://github.com/flisk-sh/flisk) runs the user's whole app on their own computer with one command: frontends, APIs, workers, AI agents and MCP servers, with their databases. Use it when the user asks you to build, run, check or fix an app on their laptop.

The `flisk` MCP server from this extension gives you the Flisk tools (`doctor`, `up`, `status`, `logs`, `resource_create`, `project_init` and more). It runs in the folder Gemini CLI was started in; pass `projectPath` (the absolute path of the folder that holds `.flisk/project.json`) when the project is somewhere else. Without the tools, run the same steps as shell commands.

- The Flisk CLI must be installed: `npm install -g @flisk-sh/flisk`. Check with `flisk --version`.
- New app: `flisk project <name>`, then `flisk resource <service> --type <frontend|backend|worker|agent|mcp> --stack <stack> --yes` for each service.
- Start it: `flisk up <stack>`, then check every URL from `flisk networks` and tell the user where the app is.
- When something fails: `flisk doctor`, then `flisk logs -s <service>`.
- Do not hand-write Dockerfiles, Compose files or Tiltfiles, and do not edit `.autogenerated/`: change `service.json` instead.
- Step-by-step plans for a shop, a SaaS, an AI agent or a blog are in the [Flisk skills](https://github.com/flisk-sh/flisk/tree/main/plugins/flisk/skills); start with `flisk-build`.
